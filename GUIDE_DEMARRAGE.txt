🔧 PERSONNALISATION
───────────────────

AJOUTER DES PRODUITS:
1. Ouvrir script.js
2. Chercher "const products = ["
3. Ajouter nouveau produit:

{
    id: 9,
    name: "Mon produit",
    category: "tables",
    price: 1500,
    image: "url-image",
    images: ["url1", "url2"],
    rating: 4.7,
    reviews: 20,
    description: "Description...",
    details: "Détails techniques...",
    shipping: "Info livraison...",
    care: "Entretien...",
    sizes: ["120cm", "150cm"],
    woods: ["Noyer", "Chêne"],
    badge: "Nouveau"
}

CHANGER COULEURS:
1. Ouvrir style.css
2. Chercher ":root {"
3. Modifier les variables:
   --sanguine: #VOTRE_COULEUR;
   --text-primary: #VOTRE_TEXTE;

MODIFIER TEXTES:
• Tous les textes sont en HTML
• Chercher et remplacer simplement

❓ QUESTIONS FRÉQUENTES
──────────────────────

Q: Comment ajouter un vrai système de paiement?
R: Intégrer Stripe ou PayPal dans la fonction handleCheckout()

Q: Comment ajouter une base de données?
R: Créer API REST (Node.js) et remplacer "const products" par fetch()

Q: Comment ajouter l'authentification?
R: Ajouter section Login/Register et JWT tokens

Q: Le site est compatible quel navigateur?
R: Chrome, Firefox, Safari, Edge (2020+)

Q: Les images viennent d'où?
R: Unsplash (placeholder). Remplacer par vos images réelles.
