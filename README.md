# Atelier Sanguine 🪵

Site vitrine d'une ébénisterie sur mesure bordelaise, au design épuré inspiré d'Apple (dark mode, frosted glass, typographie serrée, bento grid).

## Structure

| Fichier | Rôle |
|---|---|
| `index.html` | Structure sémantique de la page |
| `style.css` | Styles (variables, animations, responsive) |
| `script.js` | Nav dynamique, reveals au scroll, parallaxe sticky, compteur animé, modale de contact |

## Fonctionnalités

- **Navigation frosted glass** qui apparaît au scroll
- **Section sticky** avec zoom parallaxe et textes synchronisés au défilement (+ points de progression)
- **Bento grid** style Apple Vision Pro avec effets hover
- **Compteur animé** déclenché à l'apparition
- **Modale de contact** avec formulaire (backdrop flouté, fermeture Échap/clic extérieur)
- **Section valeurs** (bois local, fait main, garantie à vie)
- **Accessibilité** : `prefers-reduced-motion`, HTML sémantique, attributs ARIA
- **SEO** : meta description, Open Graph, images lazy-loading

## Lancer le site

Ouvrez simplement `index.html` dans un navigateur — aucune dépendance, aucun build.
